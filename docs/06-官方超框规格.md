## 2. 官方样张看出来的硬事实

以 LOCH-JP001 GMR（702×1024，官方商品图）为准，并交叉核对 TCG 四张样张：

1. **插画铺满内框整片**（top-to-bottom、side-to-side），**最外圈花边/边框完整保留**；
   插画不是只越过卡图窗，而是把卡名条、星级、类型行、文本框背后的区域全部填满。
2. **没有卡名条**。卡名直接印在插画上，按稀有度走金/银箔面，外加**深色描边**；
   等级星、属性章也直接浮在画上，没有实心底板。
3. **文本框是半透明面板**，而且**把类型行一起包进来**；面板有**金边 + 投影**，
   类型行深字在面板内，不是裸压在画上；面板上沿只比类型行高 **18px@702（≙21px@813）**，
   类型行紧贴正文上方（间隙约 7px）。不同卡框的面板底色跟着框色走（米 / 粉 / 紫）。
   魔法/陷阱同理：OCG 把 `【魔法カード】/【罠カード】` 印在类型行右侧（不是卡名下方，
   卡名下方是 TCG 的做法），所以超框档也放在面板内右侧、用面板深色墨。
4. **卡号在面板上沿外侧**，白/金 + 深描边。
5. **密码区被画面盖住**（不显示）。
6. **版权行不覆盖**：插画在版权表记上方截断，版权留在底边。
7. **插画是整卡重新构图**，不是把方窗图放大；官方样张的构图与普通版明显不同。

## 3. 本项目的实现值（REF 813×1185）

| 项 | 官方样张（折算） | 本项目 `overframe` | 说明 |
|---|---|---|---|
| 插画矩形 | 内框整片 | `frame_inset` = (28, 28, 757, 1128)，下边到版权上方 | 外框由卡框底图保留 |
| 插画下边界 | 版权上方 | `copyright.y - 6`（约 1141） | 版权行不被盖 |
| 卡名条 | 无 | **不回贴**（`restore_regions = ()`） | 卡名/星级/属性浮于画上 |
| 卡名填充 | 金/银箔 | 跟稀有度 `name_fx`；无箔时白字 | 深色描边 4px（REF） |
| 面板上沿 | 约 876（757/1024 折算） | 类型行上方约 21px（实测 854） | 面板紧包类型行 + 正文 |
| 面板下沿 | 约 1140（版权上方） | 版权标上方 20px（实测 1127） | **包住 ATK·DEF**，数值不露在框外 |
| 面板填充 | 半透明 | `panel_opacity = 0.88` | 金边 + 深色外线 + 内侧高光 + 投影 |
| 类型行 | 面板内、贴正文上方 | 面板内、贴正文上方（间隙 8px） | 深色墨；魔陷标签同在类型行右侧 |
| 正文墨色 | 单一墨色 | 官方档**统一墨色**（`uniform_ink`） | 不做 PSCT 关键词加粗；DIY 档保留 |
| 行距 / 段距 | 约 1.16 倍字号 / 无额外段距 | `MIN_LINE_RATIO=1.16` / `PARA_GAP=0.12` | ①②③ 连续排，不撑开 |
| 卡号 | 面板上沿外 | `panel_top − 18`，白/金 + 深描边 | 与 ATK·DEF 同一右基线 |
| 密码 | 隐藏 | `hide_password = True` | 常驻 |
| 面板外形 | 圆角 + 金边 | 圆角 10（REF）+ 金边/投影 | 左右各外扩 3px 包住类型行括号 |
| 灵摆 / 技能 | 暂无官方参考 | 自动回退标准 | `supports()` 与 `plan()` 双重兜底 |

**已知偏差（等验收后精修）**

* 面板上沿仍比官方样张高约 22px（官方面板顶折算 876，本项目实测 854）：官方正文
  起点更高，本轮先按「类型行贴正文」把内部间距对齐，面板整体位置待下一步统一。
* 官方插画是重新构图；本项目直接用用户提供的整卡竖图（推荐 832×1216），
  方图会被 cover 裁切。下一步的「扩图到整卡 / 整卡构图出图」会解决。
* PSER（棱镜碎）的整卡闪膜会叠在面板/文字之上（旧罕贵模型如此）；官方是箔在下、油墨在上。
  这属于下一步的罕贵/出框协同，不在本轮范围。
* MDPro3 的 `Picture/OverFrame/<id>.png` 原生超框通路尚未接入（见计划 P4）。

## 4. 验收点

对照 [overframe_accept.png](../workspace/out/_diag/overframe_accept.png)（内部验收图，不随仓库分发）：

1. 插画铺满内框、最外框保留；
2. 没有卡名条，卡名浮于画上；
3. 类型行贴正文上方（间隙 8px）；魔法/陷阱的卡种标签在同一行右侧、用深色墨；
   面板半透明 + 金边/投影，上沿只比类型行高 21px；
4. 卡号在面板上沿外（与 ATK·DEF 同右基线），密码隐藏；**ATK·DEF 数值在面板框内**
   （官方超框的面板一直包到版权行上方）；
5. 插画止于内框，版权行上方截断；
6. 官方档统一墨色（不做 PSCT 加粗），行距 1.16、段距 0.12。
