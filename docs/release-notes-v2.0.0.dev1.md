# CardForge 2.0.0.dev1

**把「一句话设想」锻成「能上牌桌的卡」。**  
Turn a one-sentence idea into a playable Yu-Gi-Oh! DIY card — fully local.

## Highlights

- **四步流水线**：规格 → PSCT 卡文 + Lua 脚本 → 卡图 + 卡面 → 导出上桌（EDOPro / MDPro3 / .ydk）
- **17 种卡种 · 25 种罕贵 · 6 档出框 · 10 种语言**，严格照官方实测规格（卡图窗斜切框、文本框半透明、版权行截断）
- **质量门 G1–G5 全部确定性代码**：平衡审计、脚本静态检查（844 API 白名单）、**真开一局对战的实跑验证**（ocgcore）、系列一致性、导出自检——降级永远如实标注，绝不谎报通过
- **召唤条件**：融合/同步/超量/连接/仪式的素材行、召唤限制与素材锁定，卡文与 Lua 同源生成；一段素材可叠多个筛选（官方「包含「六武众」怪兽的战士族怪兽2只」），额外召唤方法（接触召唤 ● 条目）自动生成 `Fusion.AddContactProc`
- **PSCT 校验器 39 条规则**，覆盖官方规范全部硬性错误
- **助手「星奏·艾莉娅」**：三档人格，把质量门结论翻译成人话；**LLM 只提议、内核裁决**，无 LLM 时功能不缺失
- **本机 ComfyUI 出图**：单张 / 分层（背景+主体抠底）/ 系列一致性 / 风格参考 / 工作流 JSON 导出
- **打包独立程序**：`tools/build_exe.py` 一键 onefolder，目标 Windows 机器零依赖

## dev1 之后增补（2026-10-26）

- **一段素材叠多个筛选**：`MaterialPart.also` —— 官方把「字段＋种族」写在同一段里，
  旧模型只能拆两段，素材数量直接翻倍（脚本要 6 只而不是 3 只）。三语卡文按官方语序
  合成，Lua 合成单个 AND 过滤函数；顺带修掉种族常量退化成十六进制、
  取对象段多余的「的」字、代价区域该用「从卡组把…」三处官方语序问题。
- **接触召唤**：`SummonSpec.methods` → 卡文「…以及以下方法才能特殊召唤。」+「●…」条目，
  脚本 `Fusion.AddContactProc(c,组,处理,nil,nil,SUMMON_TYPE_FUSION)`。
  已在**真 ocgcore** 里验证：引擎把接触召唤列为合法动作，除外 3 只素材后从额外卡组上场。
  同调/超量/连接的额外方法目前只生成卡文，脚本降级成注释并由 G1 提醒。
- **效果表达补齐**：表侧表示限定、`negate_card`（无效场上某张卡的效果直到回合结束）、
  诱发即时收尾句「这个效果在对方回合也能发动。」、「对方把怪兽的效果发动时」时点、
  不取对象的「从自己墓地选1只「卡名」以外的…」，以及「被战斗·效果破坏的场合」。
- **教学视频生成器** `tools/teach_video.py`：无头 Edge 深链截真实界面 + 系统当场产物
  排版 + ffmpeg 合成 MP4（示例：`workspace/out/召唤条件教学.mp4`）。
- **界面与工程**：召唤条件面板新增两组控件；URL 深链 `?card=&stage=&panel=`；
  `js/css` 改 `no-store`（浏览器对 `no-cache` 的 ES 模块会不回源直接复用旧副本）。
- 自测：smoke 17→18（新增「接触召唤上桌」）、selfcheck_lua 243→307。

## dev1 之后增补 ②（2026-10-26 晚）：反解不再篡改用户的卡

把系统自己生成的官方卡文贴回文本框，以前会**烂掉**：
「1只战士族怪兽」被读成种族「只战士族」→ 卡面出现「把自己场上1只**只**战士族怪兽送去墓地」；
召唤条件段被读成一条没人写的 ① 效果；表侧表示 / 诱发即时 / 「对方把怪兽的效果发动时」 /
「被战斗·效果破坏的场合」 / 「从卡组把…」代价 / 「「卡名」以外的」全部丢失；
G2 在界面显示「还没有脚本」的同时报 `STRINGID_SYNC`；官方代价句被自家 lint 判成 ERROR；
出图只会弹「先保存再出图」然后什么都不做。

- **种族/属性反解改成查官方词表**（25 个种族，长词优先），不再"往前吞 6 个汉字"。
- **召唤手续段不再当效果**：`summon.split_leading_block()` 在反解前摘掉投影出的第一段。
- **反解补齐**：`face_up`、`params['quick']`、`OPPONENT_ACTIVATE_MONSTER`、
  `params['destroyed_by']`、代价区域、`params['select']`、`exclude_self`
  （卡名忽略助词「的」后全等才算自己）。
- **质量门状态自洽**：内核在**副本**上投影预览脚本，界面用 `lua_preview` 区分
  「预览」与「已落盘」，不再出现"面板说没脚本、门在挑脚本的错"。
- **lint 不再生自己的气**：处理动词位置检查先摘掉代价与被动触发句式；
  ● 条目不要求冒号；提示文案统一去掉 Markdown 星号。
- **出图不再卡住**：规格有未保存改动时自动保存后继续出图。
- 回归锁：selfcheck_lua 307 → **335** 条断言（新增"官方卡文往返逐行相同"
  与"lint 不能判错自家产出"两节）；smoke 19 项、助手 81 条、端到端 26 项全绿。

## dev1 之后增补 ③（2026-10-26 深夜）：出图的提示词终于等于你写的话

反馈只有一句「生图时工作流里的提示词不符合我输入的要求」。三条链，全修：

- **词典吞字（主因）**：中文主体过去一律翻成英文标签，翻不出来的**静默丢弃**——
  实测「圣痕 / 露米艾尔 / 眼睛 / 光之翼 / 铠甲」整批消失，还冒出 `red, holding, behind`
  这类单字碎片。而本机自动选中的 Krea 2 用的是 **Qwen3-VL 文本编码器**，
  中文本来就读得懂，那句"提示词必须是英文"的前提根本不成立。
  现在档案新增 `bilingual_text_encoder`：**Qwen 系编码器 → 你的原话逐字进提示词**；
  英文词表 CLIP（animagine / pony / illustrious…）→ 仍须翻译，但翻不出来的词
  进 `untranslated` 并在界面红字点名，附两条出路。
- **导出工作流走小路**：`/api/art/workflow` 以前只收卡号，不读界面填的主体/风格，
  导出的 JSON 永远只有卡名；`character_sheet` 还把整段正向**替换**成固定版式指令。
  现在导出与出图共用同一份请求，版式指令改为**追加**、负向取**并集**。
- **默认装饰词反对用户**：写死在提示词里的「full body visible」「dramatic lighting,
  rim light」与卡种强光氛围句，会在你说「半身特写、柔和的晨光」时把要求拧回去。
  现在检测到用户自己写了取景或光照，对应的默认句**当场撤掉**（分层出图的主体 pass
  例外——全身+留白是抠底硬需求，notes 里写明）。
- 顺带：`8-bit` 不再被拆成 `8, bit`；风格前缀拼接不再产出 `artwork., 柔和的晨光` 病句。
- **界面变成对账页**：「预览工作流」新增口径徽标、「你输入的 → 实际送进模型的」
  逐字段对照（不一致标红）、丢词警告、以及"这版提示词是怎么拼出来的"逐条说明；
  「本机模型」加一列**提示词口径**（是编码器的事实，不是风格偏好）。
- 台账：每张图的 `meta` 与导出 JSON 的 `extra.cardforge` 都记
  `prompt_mode / untranslated / user_input / prompt_structure`，事后可复查。
- 回归锁：新增 `tools/selfcheck_prompt.py` **81 条断言**（含"导出 JSON 的节点文本
  == 编译结果""character_sheet 不覆盖主体""翻译档中文绝不漏进 CLIP"）。
  真机验证：本机 ComfyUI（krea2 / 8 步 / cfg 1.0 / 832² / 9.6 秒）出的图
  逐条对上中文要求（银白长直发·深红眼·白银铠甲·右手骑枪·发光白羽·半身特写·赛璐璐）。

## dev1 之后增补 ④（2026-10-26 深夜）：提示词模板 + 零 AI 的卡文整理

两件事，同一条原则：**你写进去的话，不许悄悄消失，也不许被悄悄改掉。**

### 提示词模板（12 套正统母题）

「主体（画什么）」是个空文本框，对不画画的人最难。现在表单顶部有模板下拉：
持械骑士 / 巨龙 / 咒术师 / 天使 / 恶魔 / 机械巨人 / 不死 / 深海巨兽 / 雷兽 /
荒野巨兽 + **魔法卡无人场景** + **陷阱卡伏击瞬间**。**只借结构**（单主体、
一个视点、一个光源、一处最亮），**不替你编设定**。

- 每套同时带**中文版与英文版**，进表单的语言由档案的文本编码器决定
  （Krea 2 / Qwen-Image 吃中文原话，animagine / pony 那类只吃英文标签）。
- 按这张卡的**种族 / 属性 / 卡种**排序，但 0 分的模板也留在表里 —— 推荐是排序不是删选项。
- 「存为我的模板」把当前这一版存进 `workspace/art_templates/`，跟着项目走。
- 表单已有内容时先弹对照（覆盖并套用 / 只填空白处 / 取消），不静默冲掉你写的东西。

### 零 AI 的「整理为标准文本」

卡文页新增按钮：把手写效果文本整理成标准 PSCT 描述，**只动文本、不动 IR**。

- **L1 表层归一**（永远安全）：`1.` / `（1）` / `[1]` → `①`、全角数字、
  引号按出现次序配对、半角 `: ; .` → 全角标点角色、重复标点合并。
- **L2 整段重写**只在三段守卫全过时才做：重写后再反解回来的 IR 指纹逐字相等、
  数字串相等、「」里的卡名相等。任何一道不过就退回表层，并把原因写在段上
  （例：「重写会丢掉『检索』这层语义」）。
- 召唤手续段与卡名级声明**一字不改**；术语（同步→同调 这类）**只报不改**
  —— 它们会出现在卡名里，替换会连名字一起改掉。
- 界面是逐段对照 + 状态徽标；**「采纳全部」只在「每段都识别 + 数值卡名保真 +
  校验 ERROR 不增加」三条全过时开放**，否则逐段采纳。
  「把整理结果同步进 IR」是独立显式按钮，先列反解结果再确认。

### 顺带修掉的 7 处「说话不算数」

| 症状 | 修法 |
| --- | --- |
| 手写 `1.` 被整理成 `1。` | 段号归一提到句号归一之前，句号规则不再吃数字后的点 |
| `1.5倍` 被当成段号① | 段号加 `(?!\d)` 与 1–20 护栏 |
| `"星尘龙"` 变成 `「星尘龙「` | 直引号改为按出现次序**配对** |
| 中文模板名全被压成同一个 key，互相覆盖 | 只清路径不安全字符、保留中文；不同标题自动加序号 |
| 种族打分用子串（战士族 ⊂ 兽战士族）+ 魔陷照种族打分 | 精确匹配；魔陷不参与种族/属性打分 |
| **单张工作流把「背景」字段整个丢掉** | 背景折进单张提示词；分层的主体 pass 反而清空背景（纯色底才抠得干净） |
| **术语表方向反了**：把官方简中的「同调／调整」判成民间误译 | 按 `cards_zh.cdb` 实测（同调 991／同步 0，调整 807／协调 0）纠正为「同步→同调」「协调→调整」；裁决只作用于 `zh_cn`；「翻转」限定三个上下文、`祭品` 降为 INFO |

### 三处投影缺陷（整理器的守卫把它们全照出来了）

- 自指效果被写成「**1张卡的**攻击力上升300」——官方 568 张写「这张卡的…」，
  这么写的 **0 张**。现在反解记 `self_obj`，投影出「这张卡／このカード／this card」。
- 字段 + 怪兽被写成「1**张**「圣痕」**卡**」——官方「X」怪兽 3791 张。
  现在 `card_type` 参与字段短语，取对象那半句也一起修，同一句里量词不再自相矛盾。
- 取对象后处理段重抄宾语——官方用「那只怪兽」（2756 张）。现在代词跟宾语类别走。
