# CardForge 2.0 · 模块规格与接口契约

> 本文件是**实现契约**。任何模块的实现都必须符合这里的函数签名与数据结构。
> 依赖方向严格单向：`core ← render/content/art/pool/duel ← pipeline ← server/cli`。
> 下层**不得** import 上层。

---

## 0. 通用约定

| 约定 | 规则 |
|---|---|
| 导入 | 模块顶部 `from __future__ import annotations`；全部类型注解 |
| 语言 | docstring 与注释用中文；标识符用英文 |
| 失败 | **可降级的能力失败返回 `None` 或空集合，不抛异常**；真错误抛 `core/errors.py` 里的类型 |
| 路径 | 一律走 `core/paths.py`，禁止硬编码绝对路径 |
| 序列化 | 落盘 JSON 用 `json.dumps(..., ensure_ascii=False, indent=2)`，UTF-8 无 BOM |
| 依赖 | 硬依赖仅 Pillow；fontTools/svglib/PyMuPDF/numpy 为可选，缺失时降级 |
| 中文输出 | 脚本写文件统一 `encoding="utf-8"`；控制台输出可能乱码，测试时写文件再读 |
