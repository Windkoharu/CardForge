# Release notes · v2.1.0.dev1（2026-10-27）

> 上一版：[v2.0.0.dev1](release-notes-v2.0.0.dev1.md)。
> 本版 = 官方超框验收通过后的排版精修 + DIY 出框档收拾 + 更新检测。

## 出框（Full Art）

* **官方超框（overframe）**：插画铺满内框、外框保留；无名条，名/星/属性浮于画上；
  面板包住类型行并**贴正文上方**（8px），金边/投影，下沿延到版权上方
  （**ATK·DEF 收进框内**）；卡号在面板外、与 ATK·DEF 同右基线；密码隐藏；
  魔陷卡种标签在类型行右侧（OCG 官方位置）、深色墨。
* **`art_over` 并入官方超框**：兼容别名，历史卡自动迁移，界面不再单列。
* **全画（full_bleed）**：插画真正铺满整卡（含外框），卡框 55% 叠回。
* **出血/全画/灵摆档**：类型行、卡号、密码压在插画上时按底图明暗**自适应对比**；
  怪物不再回贴空的卡种标签条。
* **箔下墨上**：整卡/卡图/文本框箔铺在正文墨色之前（PSER 的文字不再被闪膜糊住）；
  数值/星级/属性镀色与卡框边镀仍压在墨上。
* **箔纸跟插画走**：`artwork` 闪膜遮罩跟随实际插画矩形（出框后不再只闪标准窗）。

## 排版引擎

* 行距 1.12 → **1.16** 倍字号、段间距 0.28 → **0.12** 行（官方 ①②③ 连续排）。
* 长卡文字号**下探两档**（micro 15 / nano 13.5），247 字长卡文真正收进文本框，
  消掉假「已压到最小字号」溢出提示。
* 官方超框**统一墨色**（不做 PSCT 加粗）；假溢出计数修正。

## 上桌 / 导出

* **MDPro3 原生超框通路**：`.ypk` 内新增 `Picture/OverFrame/<卡号>.png`
  （704×1024 纯插画层，客户端自合成框体），`pics/<卡号>.jpg` 整卡图照旧兜底。

## 工具

* **更新检测**：`python -m cardforge update`、界面右上「更新」按钮、
  `GET /api/update/check` —— 走 api.github.com 比对远端 main 的版本号与 commit，
  网络失败友好降级，不影响本地使用。
* 自检 `tools/selfcheck_overframe.py` 扩到 **50 项**（官方超框 + DIY 档）。
