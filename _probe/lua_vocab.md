# CardForge Lua 词表（本机 ocgcore build 实测白名单）

> 由 `data/lua_api.json` 导出，而它抽取自 `vendor/scripts/`（官方运行库 + 400 张真实卡脚本）。
> **生成脚本时只允许用这里的名字。** 不在表里的名字 = 这个 build 里没有，写进去引擎就报错。

## 0. 与「通用 ygopro 记忆」不一致的地方（本机实测，务必看）

| 常见写法 | 本 build | 结论 |
|---|---|---|
| `EFFECT_TYPE_QUICK_C` | `EFFECT_TYPE_QUICK_F` | 只有 QUICK_O / QUICK_F，**没有 QUICK_C** |
| `Duel.ReturnToDeck` | `Duel.SendtoDeck(c,tp,seq,reason)` | 回卡组用 SendtoDeck（seq: 0顶 1底 2随机） |
| `Duel.Banish` | `Duel.Remove(c,reason,POS_…)` | 除外是 Remove + `REASON_*` + `LOCATION_REMOVED` 位置常量 |
| `Duel.PayLife` | `Duel.PayLPCost(tp,lp)` / `Duel.CheckLPCost` | 支付 LP 走 Cost 系列 |
| `Duel.UpdateLifePoints` | `Duel.Damage(tp,val,reason)` / `Duel.Recover(tp,val,reason)` | 效果伤害/回复用这两个 |
| `Duel.GetCounter` | `Duel.IsCanRemoveCounter` / `Duel.RemoveCounter` + `c:AddCounter/GetCounter` | |
| `RESETS_STANDARD` | 存在但**不在** `constants()` 前缀过滤里 | 可以用；`unknown()` 不检查 RESET_* 前缀 |
| `MATERIAL_*` / `SUMMON_TYPE_*` | 同上，`unknown()` 不检查这些前缀 | 可以用 |
