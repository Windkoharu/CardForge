# 游戏王卡牌设计方法论（CardForge 知识库）

> 用途：作为 CardForge「AI 造卡器」「AI 组卡器」的提示词知识素材与自动审计规则的依据。
> 来源：社区 DIY 教程、官方编码约定、竞技构筑理论、热门系列拆解（详见文末出处）。
> 建立日期：2026-10-12

---

## 0. 三层框架

游戏王的设计问题分三层，混在一起谈就会失焦：

| 层 | 核心问题 | 决定什么 |
|---|---|---|
| 单卡层 | 这张卡强不强、平不平衡 | 会不会一张卡毁掉整个系列 |
| 系列层 | 这批卡怎么构成一个「系列」 | 有没有统一语言、能不能运转 |
| 卡组层 | 40 张怎么配比 | 稳不稳、卡不卡手 |

**造卡器顺序必须是：单卡 → 系列 → 卡组。** 反过来做就是在堆卡。

## 1. 单卡层

### 1.1 平衡三角

```
        效果强度
        /      \
     代价 —— 限制
```

任何一项超配，整张卡就崩：
- 效果强 + 代价低 + 无限制 = 禁卡
- 效果弱 + 代价高 + 限制严 = 废卡（没人会放进卡组）

### 1.2 七条铁律

| # | 铁律 | 说明 |
|---|---|---|
| 1 | 别让单卡过强 | 一张卡就足以把系列变成 Tier-0，这是 DIY 最大死因 |
| 2 | 效果越少越好 | 好怪兽卡是 1–2 条强力效果，不是 6 条 |
| 3 | 类型/属性/等级 = 效果量级 | "很多卡是用它是什么，而非它写什么" |
| 4 | 系列内必须有协同 | 等级/种族杂乱的系列必然崩，差异必须有理由 |
| 5 | 一致性 > 上限 | 高上限低一致性必输给低上限高一致性 |
| 6 | 必须留有应对空间 | 打到对手无法还手 = 单人纸牌，设计失败 |
| 7 | 卡差中性为基准 | 至少 1 换 1；白嫖 +1 是设计事故 |

### 1.3 未成文规则（判断"像不像官方卡"的标尺）

| 规则 | 阈值 |
|---|---|
| 通常怪兽 ATK | 不应 ≥ 3000（蓝眼白龙为天花板） |
| 4 星以下效果怪 ATK | 不应 ≥ 2000（除非附带负面） |
| ATK 上限 | 5000 |
| 速攻效果 | 只有怪兽卡有；魔法/陷阱没有"2 速" |
| 一回合一次 | 现代卡默认 HOPT（卡名硬限制）防循环 |

### 1.4 泛用卡（Generic）雷区

被点名的"历史罪人"：`Isolde`、`Baronne de Fleur`、`Union Carrier`、`Auroradon`、`Crystron Halqifibrax`。
共同点：**素材条件太宽**，被无数无关卡组滥用，最终全部禁卡。

**硬约束：额外卡组素材条件必须绑字段，禁止"任意 2 只怪兽"。**

### 1.5 可变通性 / 可替代性（高级判据）

- **可变通**：同一张卡在不同局面有不同用法（如《月之书》可挡攻、可重复翻转效果、可解连锁、可停永续）
- **可替代**：好卡应让玩家在构筑时"需要权衡取舍"；如果一张卡毫无替代品（如《强欲之壶》），说明它太强

## 2. 系列层（archetype）

### 2.1 定义

- **archetype（字段）**：靠**卡名子串**绑定的卡集合。存在写着「『XX』卡」的卡片文本，则「XX」构成一个字段。
- **series（系列）**：主题相关但无卡效支持成字段的卡集合。
- 关键：**成员资格由卡名决定，不由机制决定。**

### 2.2 三个设计锚点（先定这三样才能开工）

1. **胜利方式**：战斗 / 效果压制 / 削血 / 混合
2. **王牌（trumps）形态**：主卡组大怪 / 融合 / 同调 / 超量 / 连接 / 仪式
3. **属性·种族绑定**：绑不绑？绑多少？（绑定越多，可借外部支援越多，需相应削弱本家）

> 这三样定了，系列的边界就有了。没定就开工 → 不连贯（incoherent）→ 必然卡手。

### 2.3 不连贯 vs 连贯

判据：**随便挑 4–6 张，能否看出其余卡在做同一件事？** 能 → 连贯；不能 → 不连贯。
不连贯的系列 brick（卡手）率显著更高。

### 2.4 「主题效果」手法

让**同一句式在多个卡上重复出现**，降低学习成本、强化身份感。
典型：Kozmo —— 所有飞船共用一种句式，所有驾驶员共用另一种。看卡图就能猜出半张卡。

**固化为造卡规则：一个系列只允许 3–5 种"方言句式"。**

### 2.5 setcode 编码规则（造卡器必须实现）

`.cdb` 的 `datas.setcode` 是字段的十六进制编码：

| 类型 | 规则 | 例子 |
|---|---|---|
| 基础系列 | `0x1` – `0xFFF` | 「Ojama」= `0x00F` |
| 扩展子系列 | 1 位 hex + 基础 3 位 hex | 「Ojama Knight」= `0x100F` |
| 双系列混合 | 两个各补到 4 位再拼接 | Fabled(53=`0x0035`)+Lightsworn(56=`0x0038`) → `0x00350038` = 3473464 |
| 三系列以上 | 继续往后拼 | 「No.62 银河眼光子龙」= Galaxy-Eyes(4219=`0x107B`)+Photon(85=`0x0055`)+Number(72=`0x0048`) → `0x107B00550048` |

### 2.6 命名查重（必须有）

字段名会**误伤同名卡**：`Cipher Soldier`（2004 年发行）因名字含 "Cipher"，被 16 年后的「Cipher」系列意外联动，官方只能靠 errata 改卡名修补。

**规则：DIY 字段命名前必须查重。** CardForge 可直接查 `cards_zh.cdb` 的 FTS5 全文索引。

### 2.7 系列规模的边界

- 系列卡数过多是失败信号：一个需要 165 张卡才能"自圆其说"的系列，通常是设计不良（HERO 是全游戏最大系列，因此分裂成大量子系列）
- 单个提交若超过 ~20 张卡，已有阅读负担

### 2.8 引擎型系列的边界

若 DIY 系列是"引擎"（外挂用），**不应能挂进所有卡组**（否则会变成下一个"勇者引擎"——免费获得一个全抗 + 康，属于典型不良设计）。引擎只为特定系列服务。

## 3. 卡组层（构筑）

### 3.1 Rule of 40

主卡组控制在 40 张，是最高的初动抽到概率。每多 1 张都在稀释核心卡的上手率。

### 3.2 五类卡位角色与配比

| 角色 | 英文 | 作用 | 推荐数量 |
|---|---|---|---|
| 初动点 | Starter | 零前置条件即可启动 | 12–15（通常满 3） |
| 展开点 | Extender | 被干扰后继续接 | 6–10 |
| 防御/手坑 | Hand Trap | 对手回合干扰 | 9–15 |
| 引擎必需件 | Garnet | 必需但抽到就卡 | 越少越好 |
| 收尾/高牌 | Bomb / Payoff | 后期定胜负 | 0–4 |
| 弹性卡位 | Flex | 针对环境 | 3–5 |

**初动点上手概率（40 张、起手 5 张）：**

| 初动数量 | 至少抽到 1 张的概率 |
|---|---|
| 8 | 69.4% |
| 12 | 85.0% |
| 13 | 87.7% |
| 15 | 91.9% |

### 3.3 功能性冗余 vs 死冗余（核心心法）

> **如果卡 B 只在卡 A 已启动后才有用，那 B 不是初动的冗余，它是展开点。**

判据：**抽到它，能不能多一条"从零启动"的路？** 能 → 冗余；不能 → 只是堆料。
这正是"手牌看起来很满、吃到阻断就崩"的根本原因。

### 3.4 Garnet（石榴石）概念

源自「宝石骑士·红榴」——展开必需的融合素材，但因为卡组没有其他方式调度它，**抽到手里就变废牌**。
规则：**任何"必需但无法调度"的组件都是设计债务**，数量必须压缩。

### 3.5 Side Deck（副卡组）

15 张，BO3 的第 2、3 局替换。定位是**"银弹"**：针对当前环境的 choke point。
常见错误：换side 过多，稀释了自身引擎的一致性。

## 4. 2026 环境趋势与竞技心法

### 4.1 「强启动 + 多运转 + 软终端」

- **强启动**：动点多、复数上手都能用、不占通召、无自肃（因此容易被外挂）
- **多运转**：初动到终端有多条路径，不是单一套路
- **软终端**：不再给"全抗 + 三色康"的绝对压制，给勉强能用的本家终端，靠 T1+T2 持续运转、用资源压死对手

### 4.2 强动作 vs 弱动作

- **强动作**：一回合只能做一次的资源扩张（如《烙印融合》《码丽丝》下级除外特召）——被打断则该回合彻底失去该资源
- **弱动作**：补点、修复资源链的行为

**阻抗要交给强动作，不要浪费在补点上。**

### 4.3 手坑与解场配置

| 环境 | 应对 |
|---|---|
| 展开系多 | 增殖的G 拉满 3 |
| 贴纸/控制系多 | 宇宙旋风 / 闪电风暴 |
| 无效系 | 无限泡影 / 原始生命态尼比鲁 |

## 5. 热门系列设计拆解

| 系列 | 核心设计手法 | 关键机制 | 可复用模式 |
|---|---|---|---|
| 闪刀姬 | 自我限制换强度 | 「主怪兽区无怪才能发动闪刀魔法」，用小轴换极大手坑空间 | **限制条款当引擎** |
| 龙拳（龙link） | 多轴联动 | 弹丸/混沌/深渊三轴共用"龙族·光暗"交集；素材按 A/B/C 分级 | **交汇点设计**：多轴共用属性/种族交集形成可互换"素材货币" |
| 码丽丝 | 资源链分层 | 主动调度件（睡鼠/白兔能单卡启动）vs 从动件（柴郡猫/三月兔只能接力） | **分级调度**：明确"头"与"身"，链条断了要有修复件 |
| 烙印 | 单运转高牌效 | 烙印融合一卡做完大半，吃灰后需 2–3 张补 | **强单点 vs 韧性的取舍** |
| 蛇眼 | 属性拉扯 | 炎属性特召点不断往返拉场值 | **同类引擎互拉**制造场值差 |
| 珠泪哀歌族 | 墓地即第二手牌 | 堆坟，一回合 3–4 个干扰点 | **资源区扩展**：墓地/除外区当资源池 |
| 白银城 | 陷阱主轴控制 | 靠魔陷减速对手、拖入长局 | **控制型节奏**：不追求 T1 大场，追求逐回合交换优势 |

**通用公式：**
> **一个能打的系列 = 1 个明确制胜点 + 2–3 条可互换启动路径 + 1 个能自我修复的资源循环。**
