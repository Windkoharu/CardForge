    怎么装进游戏

    1. 上一步点「生成 .ypk」，文件会出现在 workspace/out/，页面里也会给出下载链接。
    2. 打开 MDPro3 → 游戏设置 → 导入导出 → 导入。
    3. 文件类型选「扩展卡文件」，选中刚才那个 .ypk， 看到「导入扩展卡文件……成功」即可。
    4. 回游戏设置 → 扩展卡包，确认「启用扩展卡」是开的。
    5. 编辑卡组时按卡号或「Custom」筛选就能找到你的卡。
    为什么界面不直接写进 MDPro3 目录？
    MDPro3 的脚本装在 Data/script.zip、卡池在 Data/locales/*/cards.cdb，而这两个都会被游戏里的 「更新先行卡」整体覆盖。写进去等于放在一条会被冲掉的路径上， 而且改动官方卡池不可逆。走 .ypk 是客户端自己的正路： 一次点击导入，「清空扩展卡」可以整体回退。
    卡号说明：CardForge 默认发 210000000 以上的号。 本机官方池最大约 9999 万，不会撞号； 生成时还会拿客户端的官方卡池再核一遍，撞了会直接拦住并告诉你哪张。
